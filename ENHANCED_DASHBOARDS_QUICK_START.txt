================================================================================
TROUBLESHOOTING
================================================================================

Dashboard shows "Loading..." forever:
  → Check Network tab for failed API calls
  → Verify backend is running: curl localhost:5000/api/health
  → Check browser console for JavaScript errors

Data not displaying:
  → Verify API returns proper JSON
  → Check authentication (401 errors)
  → Check authorization (403 errors)
  → Look at Network tab response

Layout broken on mobile:
  → Clear browser cache
  → Verify viewport meta tag in HTML
  → Test in Chrome DevTools device mode
  → Check Tailwind CSS is compiling

Colors don't match mockups:
  → Verify Tailwind CSS build includes colors
  → Check correct color class names
  → Clear node_modules and rebuild: npm install

Charts not showing:
  → Verify SVG markup is correct
  → Check browser console for SVG errors
  → Ensure CSS width/height on SVG elements
