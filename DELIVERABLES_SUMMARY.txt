ROUTE STRUCTURE
  /login                      Unified login (all roles)
  /student-dashboard         Student dashboard (role=student)
  /instructor-dashboard      Instructor dashboard (role=instructor)
  /admin-dashboard           Admin dashboard (role=admin)
  All existing routes        Preserved, no changes

AUTHENTICATION FLOW
  1. User submits credentials at /login
  2. Backend validates and returns JWT + user object
  3. Frontend reads user.role from response
  4. Frontend routes to role-specific dashboard
  5. Backend enforces authorization on all endpoints
  6. Session persists via JWT in sessionStorage

SUPPORT & TROUBLESHOOTING
================================================================================

Issue: Login redirects wrong dashboard
  → Check user.role in DevTools Network tab
  → Verify backend login response includes role

Issue: Dashboard empty or "Loading..." forever
  → Check Network tab for API errors
  → Verify backend is running (curl localhost:5000/api/health)
  → Check for 401/403 responses

Issue: Cannot see enrolled courses
  → Verify student is enrolled in courses (check database)
  → Check /api/enrollments/my returns data
  → Review browser console for errors

Issue: Mobile layout broken
  → Test with DevTools device emulation
  → Check Tailwind responsive classes
  → Verify viewport meta tag in HTML
